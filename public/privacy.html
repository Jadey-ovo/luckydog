幸运可以公开，名单留在本机。

Luckydog 网页版没有数据库、业务后端、登录、广告或统计 SDK。姓名和抽奖结果全部由当前浏览器处理，应用不会把它们发送到服务器。

  • 默认仅在内存中保留名单，刷新或关闭页面即清空。
  • 勾选「在此浏览器记住名单」后，名单会写入当前网站的 localStorage。它不是加密存储，共用电脑上的其他使用者可能看到。
  • 取消勾选会删除本网站保存的名单，但保留当前页面内容，方便继续抽奖。「全部清空」会清空名单和本轮结果。浏览器的「清除此站点数据」也可移除保存内容。
  • 中奖结果仅保留在当前页面，不保存历史记录。名单不会写进网址、日志或 Issue。
  • 样式、脚本和字体均不依赖第三方 CDN。网页首次加载需要下载静态文件，加载后可断网抽奖；离线重新打开网页不作保证，长期离线请使用桌面版。

托管平台能看到什么

本网站由 GitHub Pages 托管。访问静态页面时，GitHub 会出于安全目的记录访问者 IP 地址。名单和中奖结果不随页面请求上传。下载桌面版会跳转到 GitHub Releases，并适用 GitHub 的隐私政策。

GitHub Pages 官方说明 · GitHub 隐私政策
