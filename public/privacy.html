幸运可以公开，名单留在你这里。

手动输入和 Excel 导入的名单仅在当前浏览器中处理。在线邀请和结果分享是主动选择的功能，使用时会发送对应信息至本站分享服务。

  • 网页版手动名单刷新或关闭后清空，不写入浏览器持久存储。文件在本地解析，不上传原文件。
  • 邀请报名会保存用户名和匿名浏览器标识。标识通过 Cookie 识别同一浏览器，用于限制重复报名，不能识别跨设备或清除 Cookie 后的同一人。同一邀请也不允许重复用户名。
  • 邀请名单只有持有管理凭据的发起页面可读取。发起人结束报名后不再接收新参与者；刷新或关闭发起页面会丢失管理凭据。
  • 分享结果时仅发送中奖名单和抽奖时间。持有分享链接的人均可查看，请确认名单适合公开后再生成链接。
  • 邀请链接默认五分钟有效，可选择十或三十分钟。发起人确认名单或关闭发起页面后，邀请和线上名单失效；结果分享链接也会随发起页面关闭而失效。若浏览器未能送达关闭通知，服务会在短时间内自动判定失效并清理。
  • 静态托管版本与离线桌面版不提供在线报名服务；桌面版仍在当前电脑保存手动名单。

托管服务

完整在线版由 Cloudflare Workers 托管，主动提交的报名与结果保存在 Cloudflare D1。原 GitHub Pages 入口仅提供静态页面。托管方可能记录访问 IP 与请求日志，平台备份和恢复历史有单独的保留策略。应用不使用广告或统计 SDK。

浏览器扩展、设备上的其他软件以及被修改的程序不在本应用控制范围内。请勿在公开 Issue 中粘贴真实人员名单。
