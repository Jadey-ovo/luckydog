# 24 小时个人记录与参与页改进

本分支 `codex/activity-history-24h` 供审查，尚未上线。桌面版本号保持 1.2.0；本轮不创建标签、安装包或 Release，不部署 Sites、不合并 main。

## 当前规则

- 报名按 5/10/30 分钟截止；提前截止可在原期限前恢复。
- 每轮开奖结果保存到同一活动。参与者查看本人最新状态和每轮记录，不收到他人姓名或完整中奖名单。继续抽奖可能重复中奖。
- 每次开奖只新增一轮结果，活动仍在进行；发起人可以继续抽奖，参与页会自动更新后续轮次。
- “清空返回”经二次确认后立即结束活动并重置发起页配置；关闭或刷新发起页则在最后一次在线续期约 90 秒后结束。历史记录、二维码和链接保留至活动创建满 24 小时。
- 未开奖活动被主动结束后显示“活动已结束，未进行开奖”；未开奖连接中断约 90 秒后显示中断。两者都不能继续报名或开奖。
- 关闭或刷新发起页不删除已同步记录，但会结束本次活动。管理凭据只在内存中，刷新不恢复管理。
- 创建满 24 小时立即停止访问。独立 Worker 由定时任务清理，Sites 由后续 API 请求触发清理；无流量时物理删除可能延后。清理级联删除名单与各轮记录。

此前 b0849a3 中“清空立即撤销链接”的设计已被本次需求替代。

## 状态与页面

报名开放且未报名时展示输入框、倒计时和报名说明。成功后突出用户名，自动更新提示作为辅助文案；不再展示填写说明。已截止、中断、已结束、中奖/未中奖均使用同一身份卡，配合各自状态说明。未参与者看不到他人信息。查询期限位于页底，不在正文展示 Cookie、设备切换等技术提示。

开奖后先显示“活动仍在进行 · 已开奖”，突出当前轮结果并列出本人每轮记录；活动结束后改为明确的“活动已结束”，结果与历史继续可查。失效页只显示状态，不提供返回或报名入口。404 后停止轮询；网络失败仍可重试，不冒充活动失效。

发起页移除配置状态标签、邀请说明条和页面底部清空入口。继续报名带返回箭头。无人报名到期后与中断活动均可从配置区返回重新发起。安全提示说明数据用途、访问权限与保留规则。

## 实现与迁移

0004 保留旧版原创建时间基准并把查询期改为 24 小时。0005 增加 archived 与 room_draws，回填现存最新结果；升级前已被覆盖的轮次无法恢复。

历史由结果更新触发器在同一次写入提交；同时间戳重试不会新增轮次，旧轮次重试不会覆盖新结果。归档关闭报名和管理写入，旧 DELETE 请求也只归档。历史与参与者到期级联清理。两套 SQL 迁移与 Drizzle schema/snapshot 同步更新，未改写旧迁移。
